
## 注意事项

1. **软删除**：所有查询默认过滤 `is_deleted=False`，不要查出已删除的记录。
2. **幂等性**：`upsert_document` 基于 `uuid` 做 `INSERT ... ON CONFLICT (uuid) DO UPDATE`，不能用普通 INSERT。
3. **事务**：`insert_extraction_result` 写实体和关系要在同一个事务里，要么全成功要么全回滚。
4. **不要直接写 SQL**：使用 SQLAlchemy ORM（`db/models.py` 里的模型），不要裸写 SQL 字符串。
5. **Session 管理**：使用 `db/session.py` 提供的 session，不要自己创建连接。
