### 3. 新增 `crawl_log` 表

记录每次爬取任务的执行情况：

```sql
CREATE TABLE IF NOT EXISTS crawl_log (
    id           BIGSERIAL   PRIMARY KEY,
    site_key     TEXT        NOT NULL,         -- 来源站点，如 nmpa/cde/pubmed
    task_type    TEXT        DEFAULT '',       -- full_crawl / incremental / retry
    status       TEXT        DEFAULT 'running', -- running/success/failed/partial
    total_count  INTEGER     DEFAULT 0,        -- 本次发现文档总数
    passed_count INTEGER     DEFAULT 0,        -- 成功入库数量
    failed_count INTEGER     DEFAULT 0,        -- 失败数量
    error_message TEXT       DEFAULT '',       -- 失败原因
    started_at   TIMESTAMPTZ DEFAULT NOW(),
    finished_at  TIMESTAMPTZ DEFAULT NULL,
    created_at   TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_crawl_site_key ON crawl_log(site_key);
CREATE INDEX IF NOT EXISTS idx_crawl_status   ON crawl_log(status);
CREATE INDEX IF NOT EXISTS idx_crawl_started  ON crawl_log(started_at);
```

### 4. 新增 `review_log` 表

记录每次审核操作：

```sql
CREATE TABLE IF NOT EXISTS review_log (
    id            BIGSERIAL   PRIMARY KEY,
    object_type   TEXT        NOT NULL,   -- 'entity' / 'relation' / 'document'
    object_id     TEXT        NOT NULL,   -- 对应记录的ID
    action        TEXT        NOT NULL,   -- approve / reject / update / confirm_match / reject_match
    reviewed_by   TEXT        DEFAULT '', -- 审核人
    reviewer_note TEXT        DEFAULT '', -- 审核备注
    before_status TEXT        DEFAULT '', -- 审核前状态
    after_status  TEXT        DEFAULT '', -- 审核后状态
    created_at    TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_review_object   ON review_log(object_type, object_id);
CREATE INDEX IF NOT EXISTS idx_review_reviewer ON review_log(reviewed_by);
CREATE INDEX IF NOT EXISTS idx_review_created  ON review_log(created_at);
```

## 额外职责：Neo4j 推送 Flow

新建 `flows/neo4j_push_flow.py`，负责将审核通过的实体和关系写入 Neo4j 图数据库。

### 依赖

```
pip install neo4j
```

连接配置从 `.env` 读取：
```
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=xxx
```

### 整体逻辑

```
1. 调 repository.get_approved_for_neo4j(limit) 取待推实体
2. 对每个实体执行 MERGE Cypher，写入 Neo4j
3. 调 repository.mark_entity_pushed(id, neo4j_node_id) 回填节点ID
4. 失败时调 repository.mark_entity_failed(id, error)

5. 调 repository.get_approved_relations_for_neo4j(limit) 取待推关系
6. 对每条关系执行 MERGE Cypher，写入 Neo4j
7. 调 repository.mark_relation_pushed(id, from_neo4j_id, to_neo4j_id)
8. 失败时调 repository.mark_relation_failed(id, error)
```

### Cypher 写入规范

实体用 MERGE（不重复创建）：
```cypher
MERGE (n:{entity_type} {id: $id})
SET n += $properties
RETURN elementId(n) AS node_id
```

关系用 MERGE：
```cypher
MATCH (a) WHERE elementId(a) = $from_neo4j_id
MATCH (b) WHERE elementId(b) = $to_neo4j_id
MERGE (a)-[r:{relation_type}]->(b)
SET r += $properties
RETURN elementId(r) AS rel_id
```
