# 代码地图：一篇资料从网站到雷达

以 NMPA（国家药监局）网站上的一篇公告为例。方框里是“文件 · 函数”，箭头右边是写进的表。
其他来源只在“抓”这一段不同（见最后）。

```text
抓 fetch/ ─────────────────────────────────────────────────────────────────────────────────────────
  run/scheduler.py · main                       每隔几秒一轮
    └ fetch/source_refresh.py · refresh_once    到点的来源建一条采集任务             → history_runs
        └ fetch/fetch_job.py · enqueue_fetch    放进 Redis 队列 extraction
  rq worker（采集工人）
    └ fetch/fetch_job.py · history_fetch_job    取任务、读来源、存版本
        └ fetch/sources.py · read_public        按来源目录 fetch/catalog.py 选读法（插件）
            └ fetch/site_crawler.py · read_site 网站来源；站点知识在 fetch/sites/nmpa.py
                ├ fetch/pagination.py · make_driver().iter_detail_urls   翻列表页，拿详情页网址
                ├ fetch/web_client.py · fetch_page                        打开详情页
                ├ fetch/page_parser.py · route_webpage                    取标题、日期、正文
                │   └ fetch/extractors/nmpa.py · extract_nmpa_detail      NMPA 详情页的专门提取
                └ fetch/web_client.py · download_pdf                      附件原件按 sha256 落盘
            （每个请求都经 fetch/transport.py 和 fetch/rate.py：限速、预算，不用读）

存 store/ ──────────────────────────────────────────────────────────────────────────────────────────
    └ store/history.py · finish_fetch → _publish  原件只追加，内容没变不另存
          · fetch/sources.py · project_record     从原件取标题、发布时间、事实字段（投影）
                                                  → history_versions（每个版本一行）
                                                  → history_attachment_links（附件挂在哪个页面下）
                                                  → history_runs.coverage（这次读到哪、为什么停）

洗 clean/ ──────────────────────────────────────────────────────────────────────────────────────────
  run/clean.py · main（--loop）
    └ clean/clean_stage.py · process            按块认领新版本（derived_stage_chunks）
        ├ clean/clean_text.py · clean_markdown  删导航和模板行、规范空白，记每段偏移 → derived_clean_text
        ├ clean/identifiers.py · extract        国药准字、NCT、DOI…                 → derived_identifiers
        ├ clean/profile.py · profile            资料类型、证据类别、正文全不全       → derived_profiles
        └ 同一事务里登记两种待办：
            store/index_publication.py · enqueue_versions                          → index_publications
            clean/extraction_checks.py · enqueue                                   → derived_extraction_check_tasks
  run/attachments.py → clean/derived_text.py · process → clean/attachment_parse.py（MinerU）→ derived_text
  run/checks.py → clean/extraction_checks.py · process_once → BioCheck 核对        → derived_extraction_checks
  run/measure.py · run_round → clean/measure_runs.py（只测 who_don 等）         → derived_measure_runs/_windows/_readings

存进知识库 ─────────────────────────────────────────────────────────────────────────────────────────
  run/index.py → store/index_publication.py · run_worker → process_once
    └ store/weknora_index_client.py           经桥接服务上传清洗正文 → WeKnora，回执写回 index_publications

雷达从哪读 api/routers/history.py（只走 HTTP，前缀 /api/history）────────────────────────────────────
  GET  /sources                 store/source_listing.py      来源清单、许可、能力
  GET  /records, /versions/{id} store/history.py · list_records, read_version   原件、投影、时间
  GET  /changes                 store/history.py · list_changes                  新版本流
  GET  /clean-text              clean/clean_stage.py · for_versions               清洗正文和段落偏移
  GET  /derived-text            clean/derived_text.py · for_versions              附件正文
  POST /search                  store/retrieval.py · search（WeKnora 召回，Fabric 逐条校验）
  GET  /registry-changes        clean/registry_changes.py   GET /version-differences  store/version_difference.py
  GET  /measurements            api/routers/measurements.py → clean/measurement_reads.py
  GET  /source-health           fetch/source_refresh.py · source_health
  GET  /graph/{id}/resolve      store/history.py · read_graph_resolution（图包里的对象候选，图包由 graph/ 发布）
  POST /fetch → GET /runs/{id}  雷达点名补抓：同一条 history_fetch_job 链
```

别的来源只换“抓”的那一格：`fetch/sources.py · read_public` 按插件分到

- 接口站点（openFDA、港交所、NCCN、Roche…）：仍是 `fetch/site_crawler.py`，拉取函数在 `fetch/sites/<站点>.py` 的 `api_fetcher`；
- ClinicalTrials、Europe PMC、FDA 完整回应函：`fetch/sources.py` 里的公共接口读取；PubMed：同文件的 `_read_pubmed`（全文 `fetch/pubmed_fulltext.py`）；
- WHO 疫情通报 `fetch/who_don.py`、GDELT 新闻 `fetch/gdelt_news.py`、SEC 财报 `fetch/sec_xbrl.py`；本地文件 `fetch/local_files.py`。

之后的“存”和“洗”所有来源都一样。图谱（对象库、审核、图发布）在 `graph/`，不在这条链上。
